# Trajectoire Auto

Trajectoire Auto aide les particuliers a verifier si leur demande de vente automobile peut avancer avec un professionnel automobile selectionne.

Le service est gratuit pour les particuliers. Il ne se presente pas comme un garage, n'achete pas les vehicules directement, ne promet pas de prix en ligne et ne force aucune vente.

Site officiel : https://trajectoireauto.fr/

Ressources utiles :

- Centre de confiance : https://trajectoireauto.fr/centre-de-confiance
- Guides vendeurs : https://trajectoireauto.fr/guides
- FAQ : https://trajectoireauto.fr/faq
- Avis et retours : https://trajectoireauto.fr/avis-retours

Trajectoire Auto se positionne comme un service web de verification et de mise en relation automobile pour particuliers en France. Le vendeur garde la decision finale apres analyse du professionnel : accepter, refuser, comparer ou interrompre le parcours.
